==============================
写真採点ツール 起動方法
==============================

【初回のみ】ライブラリのインストール
-------------------------------
コマンドプロンプト（またはPowerShell）を開いて、
以下を1行ずつ実行してください。

  cd C:\Users\shiny\OneDrive\デスクトップ\AI\photo_scorer
  pip install -r requirements.txt


【毎回の起動方法】
-------------------------------
コマンドプロンプトを開いて以下を実行：

  cd C:\Users\shiny\OneDrive\デスクトップ\AI\photo_scorer
  streamlit run app.py

ブラウザが自動で開きます（http://localhost:8501）


【使い方】
-------------------------------
1. ログイン（または新規登録）する
   ※APIキーは .streamlit/secrets.toml（公開版は Streamlit の Secrets）の
     GEMINI_API_KEY を自動で使う。ユーザーが入力する欄はない
2. 「写真をアップロード」で採点したい写真を選ぶ（複数選択OK）
3. 「採点開始」ボタンを押す
4. しばらく待つと結果がランキング形式で表示されます


【処理速度について】
-------------------------------
- 標準モデルは gemini-3.8-flash（1枚約0.23円、2027年1月から約0.46円）
  gemini-4-hydrogen も選べる（点差が少し広い。1枚約0.9円）
  ※gemini-2.5-flash は 2026年12月1日に終了するので外した
- 1枚の応答は約8秒かかるけど、最大20枚を同時に送るので、50枚でも1分かからない
- このプロジェクトは有料の Tier 1（1分1,000回まで）。サイドバーのRPMは初期値900
  上限は Google AI Studio の「レート制限」ページで確認できる
- 上限を超えてしまっても、APIが指示する秒数だけ待って自動で再開する
- 一度採点した写真（同じ画像データ）は、過去の結果を再利用してすぐ表示する
  採点し直したいときは、サイドバーの「採点済みの写真も採点し直す」をオンにする
  ※この機能を入れる前に採点した写真は対象外

【Supabase（ユーザー情報・履歴のDB）が止まらないようにする仕組み】
-------------------------------
- Supabaseの無料プランは、しばらく誰もアクセスしないと自動で一時停止する
  （止まると、ユーザー登録やログインで httpx.ConnectError が出る）
- GitHub Actions が3日おきにDBへ軽くアクセスして、止まらないようにしている
  ファイル: .github/workflows/supabase-keepalive.yml
- 最初に一度だけ、GitHubのリポジトリで設定が必要：
  Settings → Secrets and variables → Actions → New repository secret で
  SUPABASE_URL と SUPABASE_KEY を登録する（値は .streamlit/secrets.toml と同じ）
  登録したら、Actionsタブの「Supabase keep-alive」→「Run workflow」で一度試す
- リポジトリに60日間コミットがないと、GitHubがこの定期実行を自動で止める
  そのときはメールが来るので、Actionsタブから有効に戻す
- もし止まってしまったら：https://supabase.com/dashboard で「Resume project」を押す

【注意事項】
-------------------------------
- 対応形式: jpg, jpeg, png, webp, heic, bmp, tiff
